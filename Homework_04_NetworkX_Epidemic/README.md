# Домашнее задание №4 — SI-модель на сети аэропортов

## Задача

Смоделировать распространение инфекции по сети авиаперелётов и исследовать связь времени заражения со структурными характеристиками аэропортов.

## Что выполнено

- реализована событийная SI-симуляция по фактическим рейсам;
- исследовано влияние вероятности заражения на скорость эпидемии;
- построен взвешенный граф аэропортов в NetworkX;
- рассчитаны степень, коэффициент кластеризации и betweenness centrality;
- проанализирована связь сетевых метрик со временем заражения.

## Данные

Используется файл авиарейсов `2008.csv`; анализ ограничен январём 2008 года. Начальная точка распространения — аэропорт Allentown с IATA-кодом `ABE`. Файл данных необходимо разместить рядом с ноутбуком.

## Запуск

Основные зависимости: `pandas`, `numpy`, `networkx`, `scipy`, `matplotlib`, `seaborn`.

```bash
jupyter notebook Homework_04.ipynb
```
