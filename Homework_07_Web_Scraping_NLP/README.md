# Домашнее задание №7 — сбор датасета и NLP-регрессия

## Задача

Собрать сведения о товарах интернет-магазина и построить модель, связывающую текстовое описание товара с его ценой.

## Что выполнено

- реализован обход каталога [store.rvdural.ru](https://store.rvdural.ru/);
- извлекаются характеристики товаров и ссылки на изображения;
- результаты сохраняются в CSV и JSONL, предусмотрены checkpoint и журнал ошибок;
- данные делятся на train/test в отношении 75/25;
- тексты преобразуются с помощью TF-IDF по униграммам и биграммам;
- Ridge-регрессия сравнивается с константным baseline по MAE, RMSE, R² и MAPE;
- анализируются наиболее сильные коэффициенты модели.

## Особенности запуска

Ноутбук соблюдает `robots.txt` и не автоматизирует CAPTCHA: при срабатывании защиты требуется ручное подтверждение в браузере. Перед сбором данных следует повторно проверить правила сайта и не создавать избыточную нагрузку.

Основные зависимости: `pandas`, `numpy`, `requests`, `beautifulsoup4`, `scikit-learn`, `joblib`, `matplotlib`, `seaborn`.
