# Домашнее задание №2 — кластеризация клиентов банка

## Задача

Провести сегментацию клиентов немецкого банка методами обучения без учителя и дать содержательную интерпретацию полученных групп.

## Что выполнено

- выполнены EDA, обработка пропусков, кодирование категорий и масштабирование;
- построены K-Means, иерархическая кластеризация и DBSCAN;
- число кластеров и параметры моделей исследованы с помощью elbow-графика, silhouette score, дендрограммы и k-distance curve;
- результаты визуализированы методами PCA, UMAP и t-SNE;
- выполнено профилирование и бизнес-интерпретация сегментов.

## Данные

Набор [German Credit Data](https://www.kaggle.com/datasets/uciml/german-credit). Перед запуском файл `german_credit_data.csv` необходимо поместить рядом с ноутбуком.

## Запуск

Основные зависимости: `pandas`, `numpy`, `scikit-learn`, `scipy`, `matplotlib`, `seaborn`, `umap-learn`.

```bash
jupyter notebook Homework_02.ipynb
```
