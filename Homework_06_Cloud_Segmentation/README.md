# Домашнее задание №6 — сегментация облаков

## Задача

Обучить сверточную нейронную сеть сегментировать четыре типа облачной организации на спутниковых изображениях.

## Что выполнено

- разобрана RLE-разметка классов `Fish`, `Flower`, `Gravel` и `Sugar`;
- подготовлен многометочный датасет изображений и масок;
- реализована U-Net-подобная архитектура на PyTorch;
- обучение поддерживает CUDA и mixed precision;
- качество оценивается с помощью Dice coefficient;
- визуализированы кривые обучения, предсказанные и истинные маски.

## Данные

Используются данные конкурса Kaggle **Understanding Clouds from Satellite Images**: `train.csv` и каталог обучающих изображений. Крупный датасет и файл модели `best_cloud_unet.pt` в репозиторий не включены.

## Запуск

Основные зависимости: `torch`, `pandas`, `numpy`, `scikit-learn`, `Pillow`, `matplotlib`.

```bash
jupyter notebook Homework_06.ipynb
```
