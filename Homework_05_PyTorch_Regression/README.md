# Домашнее задание №5 — регрессия в PyTorch

## Задача

Обучить нейронную сеть аппроксимировать функцию

$$f(x,y)=\sin(x+2y)\exp\left(-(2x+y)^2\right), \quad x,y\in[-10,10].$$

## Что выполнено

- сгенерированы 20 000 точек с фиксированным seed;
- данные разделены на train/validation/test в отношении 70/15/15;
- реализована полносвязная регрессионная сеть в PyTorch;
- лучшая эпоха выбирается только по validation loss;
- на тестовой выборке рассчитаны MSE и абсолютная ошибка;
- построены графики обучения и поверхности истинной и предсказанной функций.

## Запуск

Ноутбук не требует внешнего датасета. Основные зависимости: `torch`, `numpy`, `matplotlib`.

```bash
jupyter notebook Homework_05.ipynb
```
