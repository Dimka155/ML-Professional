# Подсчёт деталей на конвейере — код работы с моделью

YOLOv8n-seg (один класс `part`), дообученная на кадрах камеры OpenMV 320×240.
В рабочей системе модель работает на Raspberry Pi 5 через NCNN (вход 320×256, ~55–60 мс на кадр).

## Состав

| Файл / папка | Назначение |
|---|---|
| `detector.py` | Детектор: загрузка модели (NCNN / ONNX / Ultralytics), letterbox, разбор выхода YOLOv8-seg, NMS, маски |
| `demo.py` | Проверка детектора на тестовых кадрах без Raspberry Pi и конвейера |
| `models/best.pt` | Итоговые веса (PyTorch, вход 320) |
| `models/best_ncnn_model/` | Та же модель в NCNN — так она работает на Raspberry Pi 5 |
| `test_frames/` | 61 отложенный тестовый кадр камеры с разметкой (полигоны YOLO), в обучении не участвовали |
| `training/detector_train.py` | Первичное обучение на фото деталей |
| `training/train_v8.py` | Дообучение на кадрах камеры и экспорт в NCNN |
| `training/eval_frames.py` | Покадровая оценка: полнота, точность, точное число деталей на кадре |
| `training/export_for_labeling.py` | Отбор кадров из записей конвейера и предразметка для Roboflow |
| `training/detector_data.yaml` | Описание датасета |

## Запуск (Python 3.8+, GPU не нужен)

```bash
pip install -r requirements.txt
python demo.py
```

Ожидаемый результат: `Кадров: 61; число деталей определено точно на 51 (84%), средняя ошибка числа 0.26`.
Кадры с найденными контурами сохраняются в `demo_out/`.
Без пакета `ncnn` демо само переключится на `models/best.pt`.

Оценка модели на тестовых кадрах:

```bash
cd training
python eval_frames.py ../models/best.pt --imgsz 320 --iou 0.4
```

Ожидаемый результат: найдено 485 из 505 деталей, полнота 96.0 %, точность 98.0 %.

## Что не входит в архив

- Полный датасет (1 667 изображений, ~35 МБ, экспорт Roboflow) и базовые веса первичного обучения — нужны только
  для повторного обучения (`train_v8.py`, `detector_train.py`, видеокарта с CUDA); могу передать отдельно.
- Записи прогонов конвейера (`recordings/`) — нужны для `export_for_labeling.py`.
- Код трекера, GUI и работы с камерой — в рабочей системе на Raspberry Pi.
